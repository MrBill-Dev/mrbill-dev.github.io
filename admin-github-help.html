GitHub Token：申請、到期、重設

後台「儲存已上架文」會用 Token 把 blog/文章slug/ 推到 GitHub。Token 過期或填錯時，文章仍會上架，但靜態分享頁不會更新。

1. 申請 Token（Fine-grained PAT）

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository 選 mrbill-dev.github.io（或你的 Pages repo）
  3. 權限：Contents 讀寫
  4. 記下申請畫面上的到期日，回到後台「全站設定」填寫

2. 寫入 Cloudflare Worker

在本機專案 backend/mrbill-worker 執行：

cd backend\mrbill-worker
.\scripts\push-github-token.ps1

或手動：npx wrangler secret put GITHUB_TOKEN 後 npx wrangler deploy

3. 到期前要重做什麼？

  • 重新申請新 Token（步驟 1）
  • 再執行步驟 2 更新 Worker secret
  • 後台按「重新測試連線」應顯示成功
  • 對已上架文章按「同步 GitHub」或再儲存一次
後台「儲存到期日」出現 Method not allowed？
代表 Worker 尚未 deploy 最新版，或 D1 未執行 migrate-github-token-meta.sql。到期日會暫存本機瀏覽器；deploy + migration 後再儲存一次即可同步雲端。
